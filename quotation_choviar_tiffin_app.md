**Date:** July 22, 2026 | **Prepared by:** Ankur Gosar

---

## 1. Project Overview
Custom end-to-end food ordering application suite tailored for daily tiffin services, including portals for customers, kitchen administrators, and delivery personnel.

## 2. Scope of Work

*   **End-User Portal:** Menu browsing, order placement, and account management (registration, login, order history, and auto-fetching addresses based on mobile number).
*   **Admin Panel & Kitchen Management:** Tools to set "Tomorrow's Menu", aggregate kitchen order summaries (e.g., total rotis/sabzis), and oversee all incoming orders.
*   **Delivery Portal:** View assigned active deliveries with customer addresses and real-time status tracking (mark as delivered).

## 3. Technology Stack & Hosting
*   **Development:** Responsive modern web technologies for both desktop and mobile devices.
*   **Hosting:** Deployed via Free Tier services (e.g., Vercel for frontend, Firebase/Supabase for backend), ensuring **zero recurring monthly hosting costs** within standard limits.
